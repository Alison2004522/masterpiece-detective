# 《名畫找碴王》Masterpiece Detective

適合國小五、六年級至國中一年級學生的名畫觀察力找不同網頁遊戲。

## 遊戲特色
- 3 道世界名畫關卡：藝術新手村、藝術觀察家、名畫終極挑戰
- 原圖與修改版並排對照，支援電腦與手機響應式操作
- 可愛兔子館長 `Usagi`（SVG 角色）與純 Web Audio API 輕快音效
- 每關 45 秒計時、1 次免費提示、3 星鼓勵式評分與最終稱號頒獎

## 本機與線上執行
- 純靜態網頁架構（HTML / CSS / JavaScript），不需後端伺服器與 API Key
- 下載後直接開啟 `index.html`，或上傳至獨立的 GitHub Repository 並啟用 GitHub Pages 即可遊玩
